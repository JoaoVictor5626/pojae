## Contexto do projeto
Aplicação web educacional POJAE, uma Plataforma de Oportunidades para Jovens Aprendizes e Estagiários desenvolvida para o CESMAC, com foco em impacto social. Usa Spring Boot com Java, HTML, CSS/Tailwind e JavaScript no frontend e PostgreSQL para armazenamento de dados.

## Padrões
- Java para o backend.
- Spring Boot para configuração do servidor e rotas.
- HTML, CSS/Tailwind e JavaScript para a interface.

## Restrições
- Mantenha o código simples e acessível para estudantes; não complique além do necessário.
- Não use Python nem frameworks frontend de aplicação de página única (React, Next.js etc.).
- Mantenha separação clara entre lógica do servidor (`src/main/java/`), templates (`frontend/`) e arquivos estáticos (`frontend/assets/`).
