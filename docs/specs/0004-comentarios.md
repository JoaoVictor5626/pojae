# Spec 0004: Comentários editoriais legados

- **Status:** Legado; fora do escopo do PRD 0001 atual

Esta spec descrevia comentários em publicações editoriais e moderação administrativa. Comentários e moderação não estão entre os requisitos funcionais atuais. Não usar este documento como contrato para as candidaturas, entrevistas ou avaliações do estágio.
