# Spec 0005: Publicações editoriais iniciais legadas

- **Status:** Legado; fora do escopo do PRD 0001 atual

Esta spec descrevia a carga inicial de publicações editoriais. O PRD atual trata de vagas de estágio e não exige publicações editoriais iniciais. Não confundir esses dados iniciais com vagas publicadas por empresas.
