# Spec 0003: Conteúdo editorial legado

- **Status:** Legado; fora do escopo do PRD 0001 atual
- **Decisão relacionada:** [ADR 0003](../adr/0003-conteudo-em-texto-puro.md)

Este documento descrevia publicações editoriais, rascunhos, autores e comentários. Esses fluxos não correspondem às ofertas de vagas do PRD atual. Não usar esta spec para implementar vagas; consulte os documentos de vagas e painel da empresa e de vagas salvas e recomendações.

O ADR 0003 continua registrando a decisão sobre escaping de conteúdo textual já persistido. A existência deste documento não mantém o fluxo editorial no escopo do produto atual.
